# /directories

No account needed. These are the first-wave directories Hustlin drafts listings for, with the fit by product type. With the `hustlin` server connected, `/launch` drafts the listing copy and tracks each one with its own link.

| Directory | Fits | Rewards |
|---|---|---|
| Product Hunt | everything | The anchor launch; traffic for days, a backlink, social proof |
| BetaList | everything, pre-launch and early | A burst of early adopters and email signups |
| Indie Hackers | SaaS, consumer, creator, dev tools | Feedback from builders; a story post does better than a listing |
| AlternativeTo | consumer, creator, SaaS, dev tools | Steady search traffic from "alternative to X" queries |
| G2 | B2B SaaS, dev tools | Buyer intent and reviews; needs real reviews to matter |
| Capterra | B2B SaaS, marketplaces | Same as G2 for SMB buyers |
| SaaSHub | B2B SaaS, dev tools | Comparison pages and a backlink |
| Uneed | everything | Daily launch list with a small engaged audience |
| Launching Next | everything | Startup directory with a backlink |
| There's An AI For That | AI products | The largest AI tool directory; category pages rank |

## How to submit well

- One description, written once, in the product's voice; a tagline under 60 characters; a 240x240 logo; 3 screenshots.
- The link in every listing should go to the funnel destination (signup page, store listing), with a tracking parameter per directory so you know which one produced customers.
- Reviews on G2 and Capterra come from asking happy users one at a time, after they have used the product for a while.
- Stagger submissions over a week; several going live on one day is wasted.
